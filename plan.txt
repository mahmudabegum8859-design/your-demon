NOTES
========================================================================
- The app will check GitHub Releases for updates: if the latest release
  version tag is higher than the current VERSION_CODE, it prompts update.
- All pentest tools live inside the Alpine chroot, not natively on Android.
- The core manager lets users install additional tools via APK (Alpine) and PIP
  inside the chroot.
- The module repository is a dynamic list fetched from GitHub at runtime.
